How to use this page

Delete this template content and write your own note here. To publish another note, copy this folder, rename it, and edit its index.html file.

Each note has its own folder with one index.html file inside it.

Use <h2> for sections within a note. You can also add quotations:

And code blocks, when needed:

def gradient_step(w, grad, lr):
    return w - lr * grad

To make this note appear on your homepage, add a new note item in the root index.html file that links to this note’s folder.
